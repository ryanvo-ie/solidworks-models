# SolidWorks Models & Engineering Drawings

This repository contains a collection of my SolidWorks models and engineering drawing sheets created as part of my coursework and continued practice with computer-aided design (CAD). These projects document my progress in learning how to create, dimension, and communicate mechanical designs using SolidWorks.

Before working with SolidWorks, I gained experience using AutoCAD and created a separate GitHub repository documenting that work. While both programs are used for CAD and share concepts such as precise dimensioning, technical drawings, and geometric construction, SolidWorks has introduced me to a more 3D and feature-based modeling workflow.

This repository focuses specifically on that SolidWorks experience. It includes individual part models and their corresponding engineering drawing sheets, demonstrating skills such as sketching, applying dimensions and geometric relations, creating 3D features, and translating completed models into technical drawings.

As I continue learning SolidWorks, I plan to add more models and increasingly complex designs to this repository. Together with my AutoCAD work, these projects document my developing experience with different CAD tools and engineering design methods.

I am currently studying Industrial Engineering at Cal Poly Pomona, and these projects are part of my broader effort to develop practical experience with engineering software, technical drawing, and design.
